# Norvane — Project Map

Every source file, its size, its purpose, and what to touch for common tasks.

## Application Files

### `app/`

| File | Size | Purpose | Touch when |
|------|------|---------|-----------|
| `app/layout.tsx` | 1.3 KB | HTML shell. Sets metadata, loads Inter font, wraps in ThemeProvider | Changing page title, meta description, keywords, font |
| `app/page.tsx` | 1.1 KB | Root page. Imports and sequences all 11 section components | Reordering sections, adding/removing a section |
| `app/globals.css` | 1.0 KB | Global styles: base resets, `.section-padding`, scrollbar, `.gradient-mask-*` | Adding global utility classes |
| `app/api/contact/route.ts` | 1.4 KB | POST handler for contact form. Validates fields, logs. Needs Resend to send email | Wiring email, changing validation rules, adding fields |
